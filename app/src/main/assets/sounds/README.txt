Hotel Tycoon - bundled sound effects
Format: WAV PCM16 mono, 44.1 kHz. These six files are included and loaded at startup;
they override the built-in synthesized fallback sounds.

bell.wav      reception bell / guest arrival
footstep.wav  player footsteps
coin.wav      guest payment and furniture sale
click.wav     UI button click
place.wav     furniture placement
error.wav     invalid action / insufficient funds

All clips are original procedurally generated game audio for this project.
